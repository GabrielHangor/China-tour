# China Tour

Vue 3 SPA / PWA: карта Китая, каталог точек и маршрутов, личные поездки офлайн.

```bash
npm install
npm run dev
```

- `npm run fmt` — oxfmt
- `npm run lint` — oxlint
- `npm run build` — production-сборка

Деплой: GitHub Pages через `.github/workflows/pages.yml`. В Settings → Pages выберите GitHub Actions.

Перед поездкой откройте сайт, поставьте PWA на домашний экран и в поездке нажмите «Скачать для офлайна». `github.io` в Китае может не открываться — установленное приложение живёт из кэша.
